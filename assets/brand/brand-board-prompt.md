# Brand board generation prompt

Use case: logo-brand

Asset type: premium 16:10 brand-guidelines overview board for a cross-border modular-housing clearance and transaction platform. The company name is unresolved. Do not create a wordmark from “Modular Hub Europe”; if it appears at all, show it only once in tiny metadata as “WORKING TITLE”.

Primary request: Create a senior European identity-studio brand board built around the concept “Controlled passage”. The abstract symbol combines a rectangular building module, a strict vertical jurisdiction boundary and an aligned clearance opening. It must communicate verified fit across a border, not a house, location or speed.

Brand strategy:
- audiences: buyers spending EUR 180,000–350,000 and Polish modular manufacturers entering Germany and the Netherlands;
- emotional promise: certainty before commitment;
- personality: precise, calm, direct, serious but not cold;
- visual world: technical dossier, transport and installation evidence, controlled cross-border process;
- core line: “CHECKED BEFORE IT CROSSES.”

Scene/backdrop: a refined 3 × 3 editorial grid on a Deep Navy outer canvas, with Warm Paper presentation panels, strong gutters and generous negative space.

Panels:
1. large abstract Clearance Gate symbol, no final wordmark;
2. construction grid showing module, boundary and aligned opening;
3. restrained desktop assessment UI fragment with a decision, document count and aligned EUR dimensions;
4. the exact line “CHECKED BEFORE IT CROSSES.” in engineered condensed grotesk;
5. colour system labelled only with exact values “#10263D”, “#F4F1EA”, “#175CD3”, “#263746”;
6. typography specimen using condensed engineering sans, neutral sans and tabular monospaced numerals such as “EUR 248 600”, “3.20 m”, “DE / NL”;
7. documentary industrial image: real rectangular modular unit secured on a semi-trailer, no house roof;
8. monochrome dossier cover and circular inspection stamp with symbol, date and reference ID;
9. trailer-side and 16 px app-icon applications of the same symbol.

Style/medium: premium identity-deck presentation, flat vector identity elements plus restrained photorealistic industrial documentary crops. Orthogonal Swiss/engineering grid, thin datum rules, registration marks, small page numbers, crisp alignment, subtle paper and steel texture. No gradients anywhere.

Lighting/mood: neutral industrial daylight; calm, authoritative, materially honest; restrained saturation.

Color palette: dominant Deep Navy #10263D and Warm Paper #F4F1EA, one brand accent Passage Blue #175CD3, Technical Graphite #263746 and steel neutrals. Do not use green, amber, red, terracotta or ochre anywhere on the board.

Typography: IBM Plex Sans Condensed character for headings, Inter-like neutral body, IBM Plex Mono character for data; readable text only, no tiny fake paragraphs.

Text (verbatim): “CHECKED BEFORE IT CROSSES.”, “CONTROLLED PASSAGE”, “EUR 248 600”, “3.20 m”, “DE / NL”, “DOSSIER 0427”, “04.08.2026”, “#10263D”, “#F4F1EA”, “#175CD3”, “#263746”. Do not add promotional slogans or fake paragraphs.

Constraints: original simple geometric mark with a strong monochrome silhouette; consistent mark across every panel; legible as a favicon; one horizontal placeholder arrangement, symbol-only and monochrome examples; clear visual distinction between brand blue and compliance status concepts; polished, sparse and implementation-minded.

Avoid: pitched-roof house silhouette, map pin, checkmark as logo, leaf, tree, globe, Europe map, national flags, shield, location route, green/amber/red accents, gradients, 3D, glassmorphism, glossy architectural renders, families on lawns, smiling stock advisers, generic proptech imagery, decorative arrows, random icons, copied trademarks, fake unreadable interface text and watermarks.
