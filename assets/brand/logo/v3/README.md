## Zasady

- V3 jest znakiem display: minimalna szerokość pełnego lockupu to 480 px lub 140 mm.
- Do faviconu, aplikacji, stopki PDF, pieczątki i druku jednokolorowego używaj płaskiego systemu v2.
- Warianty transparentne są przygotowane z rastrowego mastera. Używaj ich na spokojnym tle Warm White; na ciemne tło potrzebny jest osobny master reversed.
- Nie rozciągaj, nie pochylaj i nie zmieniaj proporcji symbolu względem logotypu.
- Nazwa pozostaje robocza; przed produkcją wielkoformatową wymagane są decyzja namingowa i finalny master wektorowy/3D.
